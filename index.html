RÝNI

Self-hosted, privacy-preserving web analytics — no cookies, no fingerprinting, respects Do Not Track.

Install via Helm

helm repo add ryni https://ryni.secanis.ch/
helm repo update
helm install ryni ryni/ryni \
  --version 0.0.1-rc1 \
  --set ingress.hosts[0].host=analytics.example.com \
  --set pocketbase.persistence.storageClass=longhorn

Why RÝNI

  • Two tracking modes: a direct script, and a same-origin proxy that adblockers can't block.
  • Per-site dashboards: views, unique visitors, durations, bounces, and referrer/browser/OS breakdowns.
  • Per-site roles (viewer / manager) plus a global admin with SSO (OIDC) and backups.
